# 📄 Convertisseur de Fichiers & Outils PDF

Une solution web moderne, rapide et intuitive pour convertir vos documents (Word, PDF, EPUB, MOBI) au format **Amazon KDP** et gérer tous vos fichiers PDF (compression, fusion, division, sécurisation) en un rien de temps.

---

## 🚀 Fonctionnalités principales

- **🔄 Conversion Multi-formats** : Convertissez des fichiers Word, PDF, EPUB et MOBI vers le format Amazon KDP et vice-versa.
- **🔒 Sécurisation PDF** : Protégez vos documents PDF sensibles avec un chiffrement.
- **⚡ Compression PDF** : Réduisez la taille de vos fichiers sans perte perceptible de qualité.
- **🧩 Fusion & Division** : Regroupez plusieurs PDF en un seul document ou divisez un PDF volumineux en plusieurs fichiers plus petits.
- **👁️ Prévisualisation dynamique** : Visualisez vos fichiers avant et après la conversion pour vérifier le rendu.
- **🛡️ Sécurité & Confidentialité** : Traitement sécurisé pour garant la protection de vos données.

## 🧰 Installation et Utilisation

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/votre-utilisateur/convertisseur-de-fichiers.git
   ```

2. **Ouvrir le projet :**
   Naviguez dans le dossier du projet et ouvrez le fichier `index.html` directement dans votre navigateur web préféré.

   ```bash
   cd convertisseur-de-fichiers
   open index.html  # Sur macOS
   # Ou double-cliquez simplement sur index.html
   ```
